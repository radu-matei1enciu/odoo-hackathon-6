# Solar-Powered Adaptive Website (working title)

## Context

This is a hackathon project with a solarpunk theme, meant to be demonstrated on a laptop.

## What this is

A small solar-powered server that serves a website which renders differently depending on its battery level and other conditions. The website has tiers based on the battery level. The more energy the server has, the richer the website it serves. The less it has, the simpler it gets, favouring function over form.&#32;

Notes:

- What the tiers are is not fully decided yet.
- Functionality of features does not change, only what the feature or page looks like.

## The situation

We live in a solarpunk future. Servers are more localized and small, and they are powered by renewable sources such as solar. Their batteries store energy from solar panels, wind turbines and other ecological sources, and those sources sometimes stop.
